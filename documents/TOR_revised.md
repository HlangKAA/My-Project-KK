## 1. ที่มาและความสำคัญของปัญหา

ในปัจจุบัน ทักษะการเขียนโปรแกรมคอมพิวเตอร์ โดยเฉพาะภาษา Python กลายเป็นทักษะพื้นฐานที่มีความสำคัญอย่างยิ่งในยุคดิจิทัล อย่างไรก็ตาม ผู้เรียนที่เริ่มต้นศึกษาด้วยตนเองมักประสบปัญหาความซับซ้อนของเนื้อหาและการขาดแรงจูงใจในการฝึกฝนต่อเนื่อง โดยเฉพาะเมื่อเข้าสู่หัวข้อเฉพาะทาง เช่น การประมวลผลภาพ (Computer Vision) ที่เกี่ยวข้องกับการประมวลผลข้อมูลภาพ ซึ่งต้องใช้ความเข้าใจทั้งทางตรรกศาสตร์และคณิตศาสตร์ควบคู่กัน

ปัญหาหลักที่พบคือ สื่อการเรียนรู้ส่วนใหญ่มักอยู่ในรูปแบบของเอกสารหรือวิดีโอสาธิต ซึ่งขาดการโต้ตอบแบบเรียลไทม์ (Interactive) และเมื่อผู้เรียนเผชิญกับข้อผิดพลาดของโค้ด (Syntax Error) มักไม่เข้าใจสาเหตุที่ชัดเจนเนื่องจากข้อความแจ้งเตือนมีความเป็นเทคนิคเกินไป นอกจากนี้ การติดตั้งสภาพแวดล้อมเพื่อฝึกเขียนโปรแกรมยังเป็นอุปสรรคสำหรับผู้เริ่มต้นที่มีอุปกรณ์จำกัด

จากปัญหาดังกล่าว โครงงาน "The Lost Spectrum" จึงถูกพัฒนาขึ้น โดยนำแนวคิด Game-based Learning มาประยุกต์ใช้ในการสร้างสภาพแวดล้อมที่ผู้เรียนสามารถฝึกเขียนโค้ดเพื่อแก้ปัญหาในโลกแฟนตาซีได้ทันทีผ่านเบราว์เซอร์ การออกแบบสถาปัตยกรรมแบบแยกส่วน (Modern Web Architecture) ยังช่วยให้ระบบมีความเสถียรและรองรับการขยายเนื้อหาที่ซับซ้อนขึ้นในอนาคต โครงงานนี้ไม่เพียงช่วยส่งเสริมการเรียนรู้เชิงรุกและมีส่วนร่วม (Engagement) แต่ยังเป็นต้นแบบสำหรับการพัฒนาสื่อการสอนดิจิทัลเชิงโต้ตอบที่มีประสิทธิภาพในอนาคตอีกด้วย

## 2. วัตถุประสงค์

1. เพื่อพัฒนาเว็บแอปพลิเคชันส่งเสริมการเรียนรู้การเขียนโปรแกรมภาษา Python และพื้นฐานการประมวลผลภาพ ผ่านรูปแบบเกมที่มีปฏิสัมพันธ์กับผู้ใช้งานแบบเรียลไทม์
2. เพื่อพัฒนาระบบประมวลผลภาษา Python บนเบราว์เซอร์ที่ทำงานร่วมกับระบบคำใบ้ตามลำดับขั้น (Progressive Hint System) สมุดคู่มือการเรียนรู้ (Grimoire) และหนังสือคาถา (Spell Book) เพื่อลดอุปสรรคและเพิ่มแรงจูงใจในการเรียนรู้สำหรับผู้เริ่มต้น

## 3. ขอบเขตโครงงาน

โครงงานนี้ได้กำหนดขอบเขตของเนื้อหาหลักสูตร (Curriculum Scope) ออกเป็น 4 ภูมิภาค (Regions) รวมทั้งสิ้น **29 ด่าน** เชื่อมโยงกับการเคลื่อนที่ของตัวละคร การแก้ปริศนา และการจัดการค่าสี RGB ในโลกของเกม ดังนี้

- **Region 1 (The Red Forest — 7 ด่าน):** เน้นพื้นฐานภาษา Python เพื่อสั่งการตัวละคร ได้แก่ การแสดงผล (`print`), ตัวแปรและชนิดข้อมูล (`str`, `int`, `float`, `bool`), สตริงและ `f-string`, คำสั่งเงื่อนไขเบื้องต้น (`if/else`), การวนซ้ำด้วย `for` และการสร้างฟังก์ชัน (`def`) ที่รับพารามิเตอร์
- **Region 2 (The Scholar's Archive — 8 ด่าน):** เน้นการคำนวณและแปลงค่าสี RGB ด้วยตัวดำเนินการทางคณิตศาสตร์และฟังก์ชัน ได้แก่ การเพิ่มความสว่างของสี, การปรับแต่งช่องสี (Channel Tint), การกลับค่าสี (Color Inversion), การแปลงภาพเป็นระดับสีเทา (Grayscale), การผสมสี และการวนลูปปรับค่าสีในแถวพิกเซล
- **Region 3 (Whispering Caverns — 7 ด่าน):** เน้นการจัดการโครงสร้างข้อมูลรายการ (List) และลิสต์ซ้อน (`[[r, g, b], ...]`) แทนแถวพิกเซล การเข้าถึงและสลับตำแหน่งด้วย Index การค้นหาค่าสูงสุดและตำแหน่งด้วย `max()` และ `.index()` และการวนซ้ำด้วยคำสั่ง `for`
- **Region 4 (Ash Peaks — 7 ด่าน):** เน้นตัวดำเนินการเปรียบเทียบ ตรรกศาสตร์แบบ Boolean (`and`) และการเขียนคำสั่งตรวจสอบเงื่อนไข (`if / elif / else`) เพื่อประยุกต์ใช้ในการคัดกรองและประมวลผลค่าสี เช่น การทำ Thresholding, การสร้าง Color Mask และการตรวจจับขอบเขตสี (Boundary Detection)

ขอบเขตการทำงานของระบบแบ่งออกเป็น 3 ส่วนหลัก ได้แก่ ผู้ใช้งาน (User), ระบบ (System) และผู้ดูแลระบบ (Admin) ดังรายละเอียดต่อไปนี้

| :---: | --- | --- | --- |

## 5. ผลที่คาดว่าจะได้รับ

- ได้เว็บแอปพลิเคชันสื่อการเรียนรู้ "The Lost Spectrum" ที่มีประสิทธิภาพและเสถียร โดยใช้สถาปัตยกรรมแบบแยกส่วน (Decoupled Architecture) ระหว่าง React และ Flask เชื่อมต่อกับฐานข้อมูล PostgreSQL บน Supabase
- ผู้เรียนสามารถเขียนโปรแกรมภาษา Python เบื้องต้น (ตั้งแต่ตัวแปร ฟังก์ชัน ลิสต์ ลูป ไปจนถึงคำสั่งเงื่อนไข) และเข้าใจแนวคิดพื้นฐานของการประมวลผลภาพ เช่น การจัดการค่าสี RGB การเข้าถึงข้อมูลแบบตาราง (Nested List) และการคัดกรองค่าสีด้วยเงื่อนไข (Thresholding)
- ช่วยลดอุปสรรคในการเริ่มต้นเขียนโปรแกรมด้วยการรันโค้ดผ่านเบราว์เซอร์ได้ทันที และเพิ่มแรงจูงใจในการเรียนรู้ผ่านองค์ประกอบของเกม (Gamification) เช่น เนื้อเรื่อง ระบบคะแนน XP และเลเวล ระบบความสำเร็จ กระดานอันดับ รวมถึงสมุดคู่มือ (Grimoire) และหนังสือคาถา (Spell Book)

ผู้จัดทำจึงขอปฏิบัติงานตามขอบเขตของโครงงานที่ได้เขียนไว้ข้างต้น
